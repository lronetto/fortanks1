Novo Tipo de Certificado
Nome único para identificar este tipo de certificado
Formato JSON: Defina os campos específicos que este tipo de certificado deve ter.
Exemplo:
{"campos": [{"nome": "nota_fiscal", "tipo": "text", "label": "Nota Fiscal", "obrigatorio": true}, {"nome": "numero", "tipo": "text", "label": "Número", "obrigatorio": true}]}
Tipos disponíveis: text, number, date, email, tel, url, textarea
