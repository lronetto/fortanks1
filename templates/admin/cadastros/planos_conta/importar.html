Instruções para Importação

Para importar Planos de Conta, você precisará:

  1. Selecionar um arquivo Excel (.xlsx ou .xls)
  2. Escolher a planilha que contém os dados
  3. Mapear as colunas para os campos do sistema:
    • Código: Código único do plano de conta (obrigatório)
    • Descrição: Descrição do plano de conta (obrigatório)
    • Índice: Índice para categorização (opcional)

Códigos que já existem no sistema serão ignorados.
