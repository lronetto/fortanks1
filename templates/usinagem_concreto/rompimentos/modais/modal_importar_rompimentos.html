Importar Rompimentos de Planilha Excel
Instruções:
  • O arquivo deve estar no formato Excel (.xlsx ou .xls)
  • Colunas obrigatórias: Número de Série, Data de Rompimento
  • Colunas opcionais: Data de Moldagem, Resultado (kg), Fator de Conversão, Tipo de Rompimento, Observações, Usinagem ID
  • O sistema tentará identificar automaticamente as colunas pelo nome
Formatos aceitos: .xlsx, .xls
